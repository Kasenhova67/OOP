# Курсовая работа на тему "Консольное приложение для планирования задач с синхронизацией с Google Calendar"
выполнена студенткой группы 353504 Гусенцовой Екатериной
Работа будет выполнена на языке Python.

## Описание проекта: 
Консольное приложение для планирования дел, интегрированное с расписанием учебных занятий БГУИР. Приложение позволяет пользователям управлять задачами, устанавливать для них сроки (дедлайны) и синхронизировать эти дедлайны с расписанием занятий. Приложение будет реализовано в виде консольной утилиты, что позволит пользователям взаимодействовать с ним через командную строку.

## Функциональность приложения:

**● Добавление задачи:**
_**Описание:**_ Пользователь вводит название задачи, описание и дату/время дедлайна.
**_Детали: _**
Приложение запрашивает у пользователя название задачи.
Приложение запрашивает описание задачи.
Приложение запрашивает у пользователя дату и время дедлайна (должно быть в определенном формате, например, YYYY-MM-DD HH:mm). Должна быть проверка корректности формата.
Создается объект Task.
Задача добавляется в список задач TaskManager.
Приложение выводит сообщение об успешном добавлении задачи.
Дополнительно: Пользователь может указать, связана ли задача с занятием, и тогда дедлайн будет автоматически соответствовать времени занятия (см. пункт 2).

**● Синхронизация дедлайнов с расписанием:**
_**Описание:**_ Автоматическое добавление дедлайнов для задач, связанных с учебными занятиями, на основе расписания iis.
_**Детали:**_
При создании задачи пользователь может указать, связана ли она с определенным занятием.
Если задача связана с занятием, приложение автоматически устанавливает дедлайн, соответствующий времени начала занятия (полученному из расписания).
Для этого необходимо сопоставить название задачи с названием занятия, указанным в расписании.
Если задача не связана с занятием, пользователь указывает дедлайн вручную.
Приложение отображает информацию о дедлайнах, включая информацию о связанных занятиях.

**● Просмотр списка задач:**
_**Описание:**_ Отображение списка всех задач, хранящихся в системе, включая информацию о связанных занятиях.
_**Детали:** _
Приложение выводит список задач в формате, удобном для чтения (например, ID, название, дата дедлайна, статус (выполнена/не выполнена), связано ли с занятием, название занятия).
Если список задач пуст, выводится соответствующее сообщение.

**● Отметка задачи как выполненной:**
_**Описание**:_ Пользователь отмечает задачу как выполненную.
_**Детали:**_
Приложение запрашивает ID задачи, которую нужно отметить как выполненную.
Проверяет, существует ли задача с указанным ID.
Если задача найдена, она отмечается как выполненная (поле completed в объекте Task устанавливается в true).
Приложение выводит сообщение об успешной отметке.


**● Удаление задачи:**
**Описание:** Удаление задачи из списка задач.
_Детали:_
Приложение запрашивает ID задачи, которую нужно удалить.
Проверяет, существует ли задача с указанным ID.
Если задача найдена, она удаляется из списка задач.
Приложение выводит сообщение об успешном удалении.

## Описание моделей данных для консольного приложения Task Manager
В  проекте Task Manager будут использоваться следующие модели данных:


**Task:**

Назначение: Представляет собой отдельную задачу, которую пользователь хочет запланировать.
Атрибуты:
id: Уникальный идентификатор задачи (строка, генерируется автоматически с помощью UUID). Используется для идентификации задач и их поиска/удаления.
title: Название задачи (строка). Обязательное поле, описывающее краткое содержание задачи.
description: Описание задачи (строка). Предоставляет более подробную информацию о задаче.
due_date: Дата и время дедлайна (объект datetime). Указывает срок выполнения задачи.
completed: Статус выполнения задачи (логическое значение - True или False). Показывает, выполнена ли задача.
related_to_lesson: Булево значение (True или False). Указывает, связана ли задача с учебным занятием.
lesson_title: Название связанного занятия (строка). Содержит название занятия, если related_to_lesson равно True.
Методы:
__init__(self, ...): Конструктор. Инициализирует атрибуты объекта Task.
__str__(self): Возвращает строковое представление задачи (для вывода в консоль).
mark_as_completed(self): Отмечает задачу как выполненную.
is_due(self): Проверяет, наступил ли дедлайн задачи.


**Lesson:**

Назначение: Представляет информацию об одном учебном занятии, полученную с сайта iis.
Атрибуты:
subject: Название учебного предмета (строка).
start_time: Время начала занятия (строка, например, “09:45”).
end_time: Время окончания занятия (строка, например, “11:20”).


**TaskManager:**

Назначение: Класс для управления списком задач и взаимодействия с API расписания БГУИР.
Атрибуты:
tasks: Список объектов Task. Хранит все задачи, созданные пользователем.
Методы:
__init__(self): Конструктор. Инициализирует менеджер задач.
load_tasks(self): Загружает список задач из файла.
save_tasks(self): Сохраняет список задач в файл.
add_task(self): Добавляет новую задачу в список.
list_tasks(self): Отображает список всех задач.
mark_task_as_completed(self): Отмечает задачу как выполненную.
remove_task(self): Удаляет задачу из списка.
get_schedule_from_bsuir(self, group_id: str, date: datetime.date) -> list[Lesson]: Получает расписание для указанной группы на указанную дату с сайта iis.bsuir.by. Возвращает список объектов Lesson.


**BSUIRScheduleAPI (API для работы с расписанием БГУИР):**

Назначение: Класс для взаимодействия с API сайта iis для получения расписания.
Методы:
get_schedule_for_group(self, group_id: str, date: datetime.date) -> list[Lesson]: Получает расписание для указанной группы на указанную дату. Возвращает список объектов Lesson. 
В зависимости от реализации, этот класс может содержать методы для отправки HTTP-запросов, парсинга HTML, обработки ошибок и т.д.


Взаимосвязи между моделями:
TaskManager содержит список объектов Task.
TaskManager использует BSUIRScheduleAPI для получения расписания.
BSUIRScheduleAPI возвращает список объектов Lesson.
Объекты Task могут быть связаны с объектами Lesson (через атрибуты related_to_lesson и lesson_title).
