## Work №1 "Basic OOP Principles"
Work done by Ekaterina Gusentsova, the student of the 353504 group.

**The task is to implement a simple Paint app. The application should be able to perform basic features such as:**

- Draw a figure with configurable parameters.
- Erase an object.
- Move an object.
- Add a background to a figure.
- Save canvas as a file.
- Load from a file.
- Undo/redo actions.
